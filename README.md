# ResolverHub
## Customer Service Knowledge-Based Resolution Platform

### Project Overview
ResolverHub is a customer service platform designed to help users find solutions to common technical problems and manage support tickets efficiently.

### Features
- **Dashboard:** Displays total, open, and resolved ticket counts.
- **Knowledge Base:** Search for solutions to common technical issues.
- **Ticket Management:** Create, view, resolve, and delete support tickets.
- **Status Filtering:** Filter tickets by their current status.
- **Database Integration:** Store and manage tickets using MySQL.
- **Responsive Interface:** User-friendly frontend design.

### Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Java, Spring Boot
- Database: MySQL
- Tools: Visual Studio Code, Git, GitHub

### Project Structure
- `frontend/` — User interface, styling, and JavaScript.
- `backend/` — Spring Boot backend application.
- `README.md` — Project documentation.

### How to Run
1. Start the MySQL service.
2. Configure the database connection in the backend application.
3. Open the backend folder in a terminal.
4. Run the application using `./mvnw.cmd spring-boot:run` in PowerShell.
5. Open the frontend using VS Code Live Server.
